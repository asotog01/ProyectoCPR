# Sistemas de Big Data

¡Bienvenido a la asignatura de **Big Data**!

En la era de la información, el volumen, la velocidad y la variedad de los datos crecen de forma exponencial. Esta asignatura está diseñada para proporcionarte las herramientas y conocimientos necesarios para gestionar grandes volúmenes de datos que las herramientas tradicionales no pueden procesar de manera eficiente.

## ¿Qué exploraremos?

A lo largo del curso, nos sumergiremos en el ecosistema de Big Data, cubriendo conceptos clave como:

1.  **Fundamentos de Big Data:** Las 5 Vs (Volumen, Velocidad, Variedad, Veracidad y Valor).
2.  **Infraestructura y Almacenamiento:** Tecnologías como Hadoop HDFS, bases de datos NoSQL (MongoDB, Cassandra) y sistemas de archivos distribuidos.
3.  **Procesamiento de Datos:** Frameworks de procesamiento masivo como Apache Spark y MapReduce.
4.  **Ingesta de Datos:** Herramientas para recolectar y mover datos (Kafka, Flume).
5.  **Análisis y Visualización:** Extracción de conocimiento mediante herramientas de BI y analítica avanzada.

## Objetivos del Curso

*   Comprender los retos que plantean los grandes volúmenes de datos en la actualidad.
*   Diseñar e implementar arquitecturas escalables para el almacenamiento y procesamiento.
*   Dominar las herramientas líderes del mercado en el ecosistema Big Data.
*   Desarrollar una mentalidad analítica para transformar datos en decisiones estratégicas.
