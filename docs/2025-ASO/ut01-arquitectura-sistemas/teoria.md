## Introducción a la Arquitectura
En este tema estudiaremos cómo se estructuran los sistemas operativos modernos (Kernel, Shell, System Calls) y la diferencia entre arquitecturas monolíticas y microkernels.

## Objetivos de Aprendizaje
*   Identificar los componentes principales de un SO.
*   Comprender el ciclo de vida de un proceso.
*   Diferenciar entre modo usuario y modo kernel.

:::info
Esta unidad sienta las bases para entender por qué ciertas configuraciones de administración afectan al rendimiento y seguridad del sistema.
:::
