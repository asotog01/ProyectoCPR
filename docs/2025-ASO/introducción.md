# Administración de Sistemas Operativos (ASO)

¡Bienvenido a la asignatura de **Administración de Sistemas Operativos**!

En este curso exploraremos los fundamentos y las prácticas avanzadas necesarias para gestionar, configurar y mantener sistemas operativos en entornos profesionales. La administración de sistemas es una pieza clave en cualquier infraestructura tecnológica, asegurando que los servicios estén disponibles, sean seguros y funcionen de manera eficiente.

## ¿Qué aprenderemos?

A lo largo de esta asignatura, cubriremos los siguientes pilares fundamentales:

1.  **Gestión de Usuarios y Grupos:** Control de acceso y permisos en sistemas multiusuario.
2.  **Administración del Sistema de Archivos:** Organización, cuotas y mantenimiento de datos.
3.  **Automatización con Scripting:** Uso de Bash y otras herramientas para simplificar tareas repetitivas.
4.  **Servicios de Red:** Configuración de servicios esenciales como DNS, DHCP, servidores web y archivos.
5.  **Seguridad y Monitorización:** Auditoría de sistemas, copias de seguridad y detección de fallos.

## Objetivos del Curso

*   Comprender la arquitectura y el funcionamiento interno de los sistemas operativos (principalmente Linux y Windows Server).
*   Instalar y configurar servicios críticos de infraestructura.
*   Implementar políticas de seguridad y planes de recuperación ante desastres.
*   Desarrollar habilidades para la resolución de problemas (troubleshooting) en entornos complejos.
